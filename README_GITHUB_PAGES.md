# Sito Vaulta

Pagina statica: non richiede build né servizi esterni. HTML, CSS, JavaScript e immagini sono locali. Nessuna analisi del traffico, form di raccolta dati o font remoto è stato aggiunto.

Menu mobile, galleria con ingrandimento, FAQ e collegamenti di acquisto. Il contenuto principale resta leggibile senza JavaScript. Il nome pubblico è Vaulta. Le immagini della UI sono reali, con dati inventati.

Il software, i database e gli archivi di lavoro non fanno parte di questo sito. Il checkout e il modulo di assistenza sono su Payhip e applicano le condizioni di quel servizio.
