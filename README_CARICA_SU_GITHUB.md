# Vaulta 5.0 - GitHub Pages Reset

Caricare su GitHub il contenuto interno di questa cartella, non la cartella stessa e non lo ZIP.

La root del repository deve contenere:

- index.html
- styles.css
- script.js
- favicon.ico
- assets/

Impostazioni GitHub Pages consigliate:

Settings > Pages
Source: Deploy from a branch
Branch: main
Folder: / root
