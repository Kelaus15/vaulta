# Come caricare Vaulta 5.0 su GitHub Pages

Carica nella root del repository il contenuto di questa cartella, non lo ZIP e non una cartella esterna.

La root del repository deve contenere:

```text
assets/
favicon.ico
index.html
script.js
styles.css
README_CARICA_SU_GITHUB.md
README_GITHUB_PAGES.md
```

Impostazione consigliata in GitHub:

```text
Settings -> Pages
Source: Deploy from a branch
Branch: main
Folder: / root
```

Dopo il caricamento attendi qualche minuto e aggiorna la pagina con CTRL + F5.
