# Pubblicare il sito Vaulta

Carica il contenuto di questa cartella nella radice del repository `kelaus15/vaulta`, mantenendo la cartella assets. Non caricare lo ZIP intero né la cartella esterna. Includi anche .nojekyll, robots.txt e sitemap.xml.

In GitHub: Settings → Pages → Deploy from a branch → main → / (root). Se il repository usa già un’altra procedura di pubblicazione, mantienila.

Il sito previsto è https://kelaus15.github.io/vaulta/. Il pulsante d’acquisto porta a https://payhip.com/b/Q5RrJ. Se cambi dominio, aggiorna canonical, og:url, og:image, robots.txt e sitemap.xml.

Su Payhip sostituisci titolo e descrizione con media-kit/copy/PAYHIP_COPY.txt del pacchetto master. Carica la nuova copertina e i file cliente aggiornati, senza database, backup, sorgenti di marketing o cartelle personali. Il sito contiene solo i materiali da mostrare al pubblico.
